## Key Insights from Research

### What We Learned

**Product Hunt (2024-2025):**
- Changed dramatically: Only 10% get "featured" (vs 60-98% before)
- Featured status = 70% of success
- Requires 8-week preparation
- Realistic expectations: 1K-5K visitors if featured, 100-500 if not

**Community-Led Growth:**
- Authentic engagement beats paid ads for early traction
- Reddit, IndieHackers, Twitter prioritized
- "Building in public" narrative works
- 6-month pre-launch community building recommended

**SEO & Content:**
- Programmatic SEO now accessible (<$100/month tools)
- AI + human editing = scalable quality
- Search volume data CRITICAL for tool prioritization
- Long-term play: 3-6 months to see results

**Paid Advertising:**
- Google Ads: $2-5 CPC for tool keywords (varies)
- Reddit Ads: Underpriced for B2B (+17x ROAS possible)
- Budget recommendation: $2K-3K/month for lean launch

**Launch Timing:**
- MVP + audience-first approach validated
- 6-month pre-launch builds momentum
- Weekly/monthly release cadence for sustained hype
