## Production Instructions for Design Team

### File Specifications
- **Resolution**: 1080x2340 pixels (iPhone 15 Pro Max)
- **Aspect Ratio**: 19.5:9
- **Format**: MP4 (H.264 video, AAC audio)
- **Frame Rate**: 30 fps
- **Duration**: 9.8 seconds (±0.2s acceptable)
- **File Size**: <500KB (for fast loading)

### Color Codes
- **Warm Peach**: #FFF8F5 (attention, slide 1)
- **Cool Blue**: #F5F8FF (trust, slide 2)
- **Purple**: #F8F5FF (intrigue, slide 3)
- **Text**: #000000 (pure black)
- **Logo Blue**: #0066FF at 25% transparency (alpha: 64/255)

### Font Specifications
- **Font Family**: Helvetica (system font)
- **Weights**: Light (index=2), Regular (index=0)
- **Sizes**: 72pt-114pt (varies by variation, see above)
- **Alignment**: Center (horizontal and vertical)
- **Anti-aliasing**: Enabled (smooth text rendering)

### Animation Timing
- **Text Fade-In**: 0.1 seconds (snappy)
- **Text Fade-Out**: 0.1 seconds (snappy)
- **Blank Pauses**: 0.25 seconds (between slides, prevents overlap)
- **Color Transitions**: 0.5 seconds (smooth psychological flow)
- **Growth Animations**: 2-3% size increase over 2.3 seconds (subtle emphasis)
- **Logo Fade**: 1 second (behind text, gradual reveal)

### Music/Audio
- **Track**: "Still" (Trap) or similar energetic trap beat
- **Duration**: Full 9.8 seconds
- **Fade-Out**: 1.5 seconds at end
- **Volume**: Normalized to -14 LUFS (Instagram standard)
- **Format**: AAC 192kbps

### Python Script Modifications

To generate new variations, modify `/Users/titan-2/Documents/workspace/convenience-pro/convenience-pro-website/channels/instagram/generate_slides_v8.py`:

**Example: Variation A (Privacy-First)**

```python
# Slide 1: Privacy messaging
def create_slide_1_variation_a():
    messages = [
        "Your files",
        "never leave",
        "your computer"
    ]

    img = create_blank_slide(COLOR_ATTENTION)  # Warm peach
    draw = ImageDraw.Draw(img)

    try:
        font = ImageFont.truetype('/System/Library/Fonts/Helvetica.ttc', 96, index=2)  # Light
    except:
        font = ImageFont.load_default()

    positions = [400, 1170, 1940]  # Top, center, bottom

    for i in range(3):
        text = messages[i]
        bbox = draw.textbbox((0, 0), text, font=font)
        text_width = bbox[2] - bbox[0]
        x = (WIDTH - text_width) // 2
        y = positions[i]
        draw.text((x, y), text, fill=TEXT_COLOR, font=font)

    img.save('slide1_variation_a.png')
```

**Repeat for each variation** (modify text, fonts, positions as specified above).

## A/B Testing Protocol

### Test Structure

**Week 1-2**: Run all variations simultaneously
- Budget: $200/variation ($1,200 total)
- Equal spend across all variations
- Track CTR, CPC, landing page bounce rate

**Week 3-4**: Double down on top 2 performers
- Budget: $400/variation ($800 total)
- Kill bottom 4 variations
- Optimize targeting for winners

**Week 5+**: Scale winners
- Budget: $1,000-$2,000/variation
- Refine messaging based on engagement
- Test new variations against winners

### Success Metrics

| Metric | Goal | Red Flag |
|--------|------|----------|
| **CTR** | >2.0% | <1.0% |
| **CPC** | <$0.60 | >$1.00 |
| **Bounce Rate** | <60% | >70% |
| **Avg. Session Duration** | >2 min | <1 min |
| **Tools Used (First Session)** | >1 | 0 |

### Decision Matrix

**If CTR is high but bounce rate is high**:
- Ad is compelling but landing page isn't delivering
- Action: Optimize landing page (speed, clarity, CTA)

**If CTR is low but CPC is low**:
- Ad isn't engaging but audience is cheap
- Action: Test new creative, keep targeting

**If CTR is high and CPC is high**:
- Competitive audience, good engagement
- Action: Optimize landing page for conversions, scale carefully

**If CTR is low and CPC is high**:
- Poor ad, expensive audience
- Action: Kill variation immediately

## Landing Page Optimization (Post-Click)

### Recommended Landing Page Flow

**URL Structure**:
- General ad: `conveniencepro.cc/?ref=ig_ad_[variation]`
- Specific tool ad: `conveniencepro.cc/tools/pdf-merger?ref=ig_ad_pdfmerger`

**Landing Page Elements** (Homepage or Tool Page):

1. **Hero Section** (Above fold):
   - Headline: "200+ Free Tools. No Sign-Ups. Privacy-First."
   - Subheadline: "Your files never leave your computer."
   - CTA: "Browse Tools" or "Try [Specific Tool]"

2. **Tool Grid** (Homepage) or **Tool Interface** (Tool Page):
   - Immediate access to tools (no click barriers)
   - Search bar (for browsing)
   - Categories (clear organization)

3. **Trust Signals** (Below fold):
   - "Client-Side Processing" explainer (1 sentence + icon)
   - "No Accounts Required" (icon)
   - "Always Free" (icon)

4. **Minimal Ads** (Side columns on desktop, hidden on mobile):
   - AdSense (non-intrusive placement)

**Mobile Optimization**:
- Tool interface first (no scrolling needed)
- Hide ads on mobile (cleaner UX)
- Fast load times (<2 seconds)

## Retargeting Campaign (Phase 2)

### Audience Segments

**Segment 1: Tool Users (High Intent)**
- Visited site + used 1+ tool
- Retarget with: "You used [Tool]. Try these 5 related tools."

**Segment 2: Browsers (Medium Intent)**
- Visited site, didn't use a tool
- Retarget with: "Still looking for [solution]? ConveniencePro has 200+ tools."

**Segment 3: Bounce (Low Intent)**
